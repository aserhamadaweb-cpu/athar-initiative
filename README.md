# ATHAR

Arabic-first site for the ATHAR youth volunteer initiative, with an English switch.

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and add the ATHAR Supabase URL, publishable key, and admin values. The admin desk is at `/admin`. From there you can edit news, links, forms, honored members, and visitor messages. Visitors can leave messages, and they cannot read them.
